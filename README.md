# 退休金試算

一個單檔網頁工具，試算勞保老年年金、勞退專戶月退休金與國民年金，再結合手上的本金與退休後支出，推估資產能撐到幾歲。

沒有任何後端，所有計算都在瀏覽器裡完成，填寫的數字不會離開你的電腦。按「存檔」是存在瀏覽器的 localStorage。

## 圖表用的是實際的每年報酬

資產走勢圖與年度明細表不是用「每年都剛好賺到平均值」的平滑曲線，而是把你指定年份起的**實際年度報酬**一年一年套進去算。年度明細多了「當年報酬」欄位，負報酬會標紅。

圖上會同時畫出平均年化的虛線做對照，下方直接告訴你兩者期末差多少 —— 平均報酬一樣、順序不同，結果可以差很多。

起跑年可以自己輸入，也可以按「最差的一年」「中位數」「最好的一年」讓程式挑。若指定年份超出所選標的的資料範圍，會自動退回最接近的年份；歷史長度不足時，末段由序列開頭循環接續，畫面上會註明。

## 報酬率怎麼決定

「投資年化報酬」欄位是唯讀的。它的值來自「用歷史報酬決定報酬率」面板：你給每個標的一個權重，選擇要用長期、近 10 年或近 5 年的年化報酬，程式按權重加權後直接套進試算。權重不必湊滿 100%，會按比例換算。

這樣做的用意是讓報酬假設有依據，而不是憑感覺填一個數字。相對地，也代表你必須自己決定要用哪個期間 —— 近 5 年的數字包含 2024–2026 的 AI 行情，用來規劃三十年的退休會嚴重高估，面板上方會即時提醒你這組配置近 5 年比長期高出幾個百分點。

## 名目金額與今日購買力

試算出來的期末資產是**名目金額**，也就是幾十年後那個時間點的數字，沒有扣掉通膨。以 2% 通膨、37 年來說，購買力會縮水約 2.08 倍。

所以介面上凡是出現期末資產的地方，都會同時標出「今日購買力」；年度明細表也多了一欄，把每一年的期末資產折回今天的幣值。看長期試算時請以這一欄為準，名目數字很容易讓人高估。

## 單位

所有金額欄位都用**萬元**（本金、年支出、勞退專戶、質押擔保品等）。投保薪資與國保月投保金額維持**元**，因為那是主管機關公告的級距。年度明細表也以萬元顯示；匯出的 CSV 為了方便再計算，維持元。

## 功能

- **年齡**：目前年齡、停止工作年齡、預計餘命
- **勞保老年年金**：A 式與 B 式擇優，並依請領年齡計算減給或增給
- **勞退專戶**：以勞保局的期初年金現值因子公式計算月退休金
- **國民年金**：A 式與 B 式，可勾選「已領其他社會保險年金」限定採 B 式
- **併計配偶**：可加入第二人，兩人的年金一起計入現金流
- **資產推估**：逐年計算投資損益、年金收入與支出（支出隨通膨遞增），輸出走勢圖與年度明細表
- **反推所需報酬**：算出讓資產全程不低於設定門檻所需的最低年化報酬率
- **報酬率由投資組合決定**：投資年化報酬不是自己填的，是依你給各標的的權重、用歷史年化報酬加權算出來，改權重或改回測期間就會即時重算整份試算
- **標的**：全球指數、S&P 500、那斯達克 100、道瓊、台灣加權報酬指數、0050、0056、00713、台積電、黃金現貨、台幣定存、SGOV
- **缺額結論**：直接告訴你有沒有缺額。有的話算出還差多少本金、或每年支出要降到多少；沒有的話說明還有多少餘裕、每年最多能花到多少
- **最差起跑年檢驗**：再告訴你若從歷史上最差的那一年開始退休，會不會出現缺額、缺多少
- **提領分析**：算出目前提領率、這筆本金真正可承受的提領率、可承受的年支出，以及每年要增加或減少多少支出（並換算成每月金額）。固定報酬率與最差起跑年兩種情況並列
- **逐年順序回測**：用真實的年度報酬、依真實先後順序，從每一個歷史年份各起跑一次，算出「撐到最後的比率」與最差的起跑年，呈現報酬順序風險
- **可指定回測年份**：自行輸入回測的起訖年份，最早可從 1990 年開始
- **股票質押模組**：以配息與年金先支應、缺口才質借，逐年計算債務、擔保品市值與維持率，標示追繳線、安全線與停止新增借款門檻
- **情境並排比較**：把不同參數組合存成多個情境，並排看期末資產、期間最低與所需報酬率
- **匯出**：CSV（年度明細、質押明細、回測結果、情境比較）與 PPTX 簡報報告

## 放到 GitHub Pages

1. 在 GitHub 開一個新的 repository，例如 `retirement-calc`，設為 Public。
2. 把 `index.html` 和 `README.md` 上傳到 repository 根目錄（網頁上用 **Add file → Upload files** 就可以，不必用指令）。
3. 進入 **Settings → Pages**。
4. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
5. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repository 名稱>/`。

若習慣用指令列：

```bash
git init
git add index.html README.md
git commit -m "退休金試算"
git branch -M main
git remote add origin https://github.com/<你的帳號>/retirement-calc.git
git push -u origin main
```

推上去之後一樣到 Settings → Pages 開啟。

檔案名稱必須是 `index.html`，GitHub Pages 才會把它當首頁。

## 表單是空白的

所有跟你個人有關的欄位（年齡、年資、投保薪資、專戶餘額、本金、支出等）都是空白的，請自己填。有預設值的只有制度性參數：勞保法定請領年齡 65、勞退平均餘命 23 年與預定利率 1.1473%、國保月投保金額 21,103 元、通膨 2%、質押的維持率門檻等，這些可以照用也可以改。

最少要填四項才會開始試算：目前年齡、預計餘命、目前可投資本金、退休後每年支出。勞保、勞退、國保的欄位留白就當作沒有，試算一樣會跑。

## 本機直接開

不需要伺服器，用瀏覽器直接開 `index.html` 就能用。

## 計算方式

**勞保老年年金**（擇優）

```
A 式 = 月投保薪資 × 年資 × 0.775% + 3,000
B 式 = 月投保薪資 × 年資 × 1.55%
```

取較高者後，每提前一年請領減 4%、每延後一年增 4%，上限各 5 年。

**勞退專戶月退休金**

```
專戶結算金額 = 現有餘額 × (1 + 年化報酬)^(起領年齡 − 目前年齡)
年金現值因子 = [1 − (1/(1+i))^Tr] ÷ [12 × ((1+i)^(1/12) − 1)] × (1+i)^(1/12)
月退休金     = 專戶結算金額 ÷ 年金現值因子 ÷ 12
```

`Tr` 是平均餘命（勞保局採 60 歲為 23 年），`i` 是勞退基金保證收益率前三年平均數。給付至平均餘命為止，不是終身。用勞保局公告範例驗算：專戶 200 萬、Tr 23 年、i 1.1473%，因子 20.239738，月領 8,235 元。

**國民年金**

```
A 式 = 月投保金額 × 年資 × 0.65% + 4,872
B 式 = 月投保金額 × 年資 × 1.3%
```

已領勞保老年年金等社會保險年金給付者只能採 B 式。

**逐年推估**

```
期末資產 = 期初資產 × (1 + 報酬率) + 年金收入 − 支出 × (1 + 通膨)^年數
```

停止工作之前的年度假設薪資剛好打平生活費，本金只複利成長、不提領。

## 逐年報酬序列

「逐年順序回測」用的是 `SERIES` 物件裡的實際年度報酬。目前收錄六個有可靠公開資料的標的：

| 標的 | 期間 | 內容 | 來源 |
| --- | --- | --- | --- |
| S&P 500 | 1926–2025 | 總報酬（含息） | slickcharts |
| 那斯達克 100 | 1986–2025 | 價格報酬 | slickcharts |
| 道瓊工業指數 | 1926–2025 | 價格報酬 | slickcharts |
| MSCI ACWI | 2009–2025 | 總報酬（ACWI ETF 代表） | chartrow |
| 黃金 | 2005–2025 | GLD 收盤價 | chartrow |
| 0050 | 2004–2025 | 還原除權息報酬 | havocFuture |
| 台幣定存 | 1990–2025 | 五大銀行一年期存款牌告利率，每年 12 個月底值平均，稅前 | 中央銀行「重要金融指標」 |
| SGOV | 2021–2025 | 年度總報酬 | Yahoo Finance |

0056、00713、台積電、台灣加權報酬指數目前沒有收錄逐年序列，選到它們時回測會自動排除並註明。要補上的話，在 `SERIES` 裡照相同格式新增即可：`{ from: 起始年, src:"來源", r:[...每年報酬%...] }`，陣列必須是連續年份、不含當年度未完成的部分。

回測年份可以自行指定，最早 1990 年。若指定的區間超出所選標的的共同資料範圍，會自動收斂到可用範圍並在畫面上顯示。

回測方式：取所有選到標的的共同年份（再套用你指定的年份區間），依權重算出混合報酬序列，再從每一個年份各起跑一次。若歷史長度短於試算年數，不足的部分會從序列開頭循環接續，畫面上會標註。

## 股票質押模組

勾選「用股票質押支應，不賣股」後會出現質押試算。邏輯是：配息與年金先支應生活費，缺口才質借；借款同時受「可借成數上限」與「停止新增借款維持率」兩個限制，借不到的部分視為被迫賣股。

維持率 ＝ 擔保品市值 ÷ 借款金額。預設追繳線 130%、安全線 250%（等於債務不超過擔保品的 40%）、停止新增借款 300%。這些都可以改。

## 歷史報酬資料怎麼更新

報酬數字寫在 `index.html` 的 `ASSETS` 陣列裡，也可以在網頁上直接雙擊表格中的數字修改。每個標的有三個期間：長期、近 10 年、近 5 年，單位是年化百分比、含息。

畫面上標示 `°` 的是概估值，請優先用下列來源換成實際數字：

| 標的 | 去哪裡查 |
| --- | --- |
| 0050、0056、00713、台積電 | Yahoo 股市各標的的「績效表現」頁，有 1／2／3／5／10 年年化（依淨值，已含息） |
| 台灣加權報酬指數 | 證交所「發行量加權股價報酬指數」IR0001，含息 |
| S&P 500、那斯達克 100、道瓊 | slickcharts.com 的逐年總報酬表；Trade That Swing 的長期年化統計 |
| 全球指數 | iShares MSCI ACWI ETF（ACWI）基金月報 |
| 黃金現貨 | World Gold Council 的 Gold Returns，或 SPDR Gold Trust（GLD）績效頁 |
| 台幣定存 | 中央銀行網站「重要金融指標」的利率表（interest.pdf），一年期存款牌告利率欄 |
| SGOV | Yahoo Finance 的 SGOV 績效頁 |

改完記得一併更新 `ASSETS_ASOF` 的日期字串。

**一個重要提醒**：近 5 年與近 10 年的數字包含 2024–2026 年的 AI 行情，遠高於長期平均。0050 近 10 年年化超過 20%，但成立以來約 9.8%。用近期報酬規劃三十年的退休，等於假設這段行情會一直持續。規劃時請用長期那一欄，把近期當成上檔而不是基準。

## 預設值與更新

程式裡的預設值是 2026 年的級距：勞保最高月投保薪資 45,800 元、國保月投保金額 21,103 元、勞退預定利率 1.1473%、60 歲平均餘命 23 年。這些數字每年可能調整，所有欄位都可以自己改。

## 免責

本工具為試算，不是投資建議，也不是勞保局或衛福部的正式核定。實際可領金額以主管機關核定為準。勞退月退休金至少每三年會依當時利率與專戶餘額重新核算。投資報酬與通膨為假設值，真實市場逐年波動；長期平均相同但順序不同，結果可能差很多。
